## 冲突与兼容修正

- 保留 Windows 独立接收线程；主窗口仍只接收状态通知，不恢复 UI 线程输入注入。
- 新开关 ID 追加到既有控件 ID 后，保留测试／观察器及其他控件编号。
- 兼容中枢输入与原生首次授权均应用账号居中设置，后续累计坐标同步更新，包含第三屏交接和跨回。
- 接收端不二次居中，避免下一次移动／点击回跳；设置由中枢状态同步，不在 QUIC 输入线路另增配置消息。旧中枢没有设置字段时保留边缘行为。
- 默认开启及显式关闭持久化均有测试；已有共边测试显式关闭新功能，避免用修改旧期望掩盖回归。
- Mac、Windows、网页提供开关；Omarchy 通过共享核心生效，本轮没有新增 Linux 本地设置开关。
