# 光标跟手性修复与实测（2026-11-02）

## 部署与修改

- 中枢 LPK、Mac、Omarchy 客户端均为 0.2.2；中枢通过 ponzs 微服启动器拖放安装。
- 移动立即发送，仅合并已经排队的更新，不再依赖固定 8 ms 发送节拍。
- Linux 坐标采用每像素 4096 单位、舍入和极小的正向边界修正，避免发送端或合成器归一化后的浮点误差落入前一个整像素。
- Mac 捕获期间不再反复回正本地光标，保持相对位移读取，日志确认 `cursor_warps=0 associate_result=0`；未修改原有跟踪增益。
- 对可能丢失的最终绝对位置做有界、同序号重复，保持新移动立即发送；接收端去重，无旧轨迹回放。
- 客户端及网页分别显示光标／键盘逻辑通道状态，分别输出指针节拍／路径／排队和键盘路径／确认统计，不记录输入字符。
- macOS 27 构建遇到宿主 proc-macro dylib 的已知 LINKEDIT strip 对齐问题，限定 build-override 保留构建工具调试信息；交付库仍使用 release 优化。

## 自动回归

- 共享传输 crate：8 项通过，包含实际 loopback QUIC、未注册证书拒绝、路径切换、暂停、过期会话、丢失最终位置恢复和提交计时回执。
- 中枢：16 项通过。
- 使用生产坐标映射器验证 13,400 组整像素、分数、单调与边界性质，全部通过。
- 两端构建、Mac 双架构签名和 DMG 验证、LPK lint、JS 语法、规格及 diff 检查通过。

## 真实链路受控测试

测试为操作系统级合成输入，不等同于真实触控板的主观体感。Mac 普通用户测试程序向 CGEventTap 提交已知位移，经实际客户端、局域网 QUIC、Omarchy 客户端及 Hyprland 注入，在独立全屏 GTK 观察窗口和合成器 IPC 核对结果；没有操作用户现有应用文档。

- 测试强制使用仅直连，确认会话来源和目标。
- 旧版本发送到 (123,39)，合成器报告 (122,38)；修复后报告 (123,39)。
- 连续 400 次一像素移动后从 (123,39) 到 (523,39)，累计位移正确。
- 单击与拖拽共 4 个按钮事件，拖拽从 (523,39) 到 (543,39)，释放位置正确。
- GTK 观察到 6 个按键／修饰键事件及 3 个非零滚动事件；键盘传输统计直发 4、确认 4、中转 0（收回操作的本地清理释放不计为新传输）。
- Ctrl+Option+Esc 后中枢 active 为空。测试清理释放控制、恢复原工作区及 Mac 光标。
- 指针直发计数非零，中转计数始终为 0，没有数据报发送错误。
- 稳定移动段源端捕获回调间隔 p95 约 22.5–24.4 ms；源端排队 p95 约 0.16–0.19 ms，接收端提交排队 p95 约 0.33–1.13 ms。
- 同一稳定段的位置包到达间隔 p95 仍约 58.3–68.5 ms，最长约 128.7–162.4 ms；提交回执往返 p95 约 104–110 ms。它们不是显示帧率或单程手感延迟。初始准备和停手间隔已从稳定段判断中排除。
- 接收端全段唯一位置间隔统计合计 422，加首个位置共 423 次更新，对应准备移动 2 次、定位 1 次、匀速 400 次及拖拽 20 次。观察窗口较少的 motion 回调不能直接当作网络丢包数。

## 应用级网络提示对照

曾仅为本应用 Mac UDP socket 请求系统响应式屏幕交互服务类别，并以相同动作复测。落点、累计移动和动作仍正确，但包到达 p95 没有稳定改善，因此未保留该实验性调整。最终恢复默认网络服务类型，未改变系统无线设置。

## 独立网络对照

- Mac 实际局域网地址 192.168.102.237；当前 Wi-Fi 为 5 GHz、160 MHz、802.11ax，信号约 -40 dBm，噪声约 -92 dBm。
- Omarchy 到本地网关 100.64.0.1：10 次，平均 0.019 ms，最高 0.028 ms。
- Omarchy 到 Mac，低频 20 次／0.2 秒间隔：0% 丢失，中位约 13.9 ms，平均 33.840 ms，最高 103.606 ms。
- Mac 到路由器 192.168.102.1：15 次，0% 丢失，平均 19.876 ms，最高 95.549 ms。
- 高频 ICMP 曾观察到更多丢失和一秒级长尾，但其优先级／限速可能不同，不将 ICMP 丢失率当成设备接力数据报丢失率。

## 结论与限制

坐标、累计位移、按钮顺序、键盘／滚动传输、紧急收回和程序内部低延迟预期通过。连续移动到达节拍仍不足以支持“等同本地鼠标丝滑”的判断，该预期不判为通过。剩余抖动应继续针对 Mac 无线、接入点、宿主接入路径及系统网络收发排查，独立 ICMP 结果说明不能只归因于设备接力中转或 GUI 注入队列。

最终自动直连优先、全局输入开启，原有布局和其他设置保留。最终交付 Linux SHA-256 与受控测试的默认网络版本一致；Mac 最终构建与实测版本 CodeDirectory hash 相同（签名时间不同会改变整体文件 SHA-256）。
