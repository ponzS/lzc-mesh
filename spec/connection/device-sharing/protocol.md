# 设备运行状态协议

客户端管理消息 `{"t":"device_enabled","id":"<device-id>","enabled":false}` 关闭同账号设备；`enabled:true` 开启。设备离线时也可保存选择。未知设备返回 `error`，不创建或改写其他账号的设备。

`state.devices[]` 的 `enabled` 是中枢持久化的整台客户端运行选择，缺失时按 `true` 兼容旧状态。`online` 表示管理连接是否存在；`sharing` 仍表示是否参与键鼠共享。整台关闭、单独键鼠暂停和账号级键鼠总暂停是不同设置。

新版客户端在首次收到自己的设备状态之前不启动共享能力。收到关闭状态后撤销输入、取消文件任务及其完成回调、停用剪贴板监视与写入、关闭蓝牙和 UDP 入口。收到开启状态时重置剪贴板基线，不重放关闭期间的数据。管理 WebSocket 保留，传输核心继续接收设置和撤销指令，不具有系统进程启动或命令执行接口。

中枢撤销关闭设备的控制会话及对等证书公布，禁止其双向剪贴板转发，并停止向它发送共享文件列表。原生文件请求携带 `X-Lzc-Mesh-Device-Id`；中枢按当前账号校验设备并为传输订阅运行状态变化，关闭或关闭后快速重开均取消旧传输。浏览器的账号文件管理不受某台设备关闭影响。该字段不替代账号认证，也不试图阻止已被攻陷的客户端使用其账号权限。

彻底休眠需要升级三端客户端。旧客户端仍可使用兼容输入协议，但不把它们缺少的新生命周期管理声称为完全支持。真正退出进程、关机或网络断开时，管理页面只能保存选择，不能启动进程。
