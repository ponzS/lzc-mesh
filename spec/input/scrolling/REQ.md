# 跨设备连续滚动

## 背景

用户通过懒猫设备接力，用 Mac 触控板控制 Linux 桌面时，双指滚动出现拖滞和不连贯。触控板既能产生很小的位移，也能产生恰好相当于滚轮整格的位移，这不应改变滚动手感。

## 需求目标

- Mac 用户双指滚动 Linux 页面时，连续位移按一致的比例传递，横向和纵向均不因位移大小切换行为。
- Mac 系统提供的惯性滚动被完整传递，结束或取消后不额外产生另一轮惯性。
- 普通鼠标滚轮继续正常工作，旧客户端仍可连接和滚动。

## 范围

Mac 与 Linux 客户端的滚动发送和接收、中枢转发、两端安装及 LPK 更新。滚动流结束和控制权交接时清理接收端滚动状态。

## 非目标

更换桌面环境、全局调整 Omarchy 输入参数、修改 Windows 客户端或模拟 macOS 的边缘回弹效果。
