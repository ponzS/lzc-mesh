# 手机键盘与触控板

## 背景

设备接力用户面前可能有多台电脑，希望只用手机控制这些设备，不需要在手机上显示远程桌面。

## 需求目标

- 登录用户从首页进入独立键盘触控板页面，选择同账号已批准、在线且开启接力的设备。
- 底部快捷栏以外的整屏作为相对触控板，采用启用轻点和三指拖拽后的妙控板式交互：单指移动和轻点，连续两次轻点为双击，双指轻点右键，双指自然滚动及可随时打断的一段惯性，三指拖拽，也支持轻点两下后滑动拖拽，抬手松开；取消长按右键和底部拖拽按钮。按已有布局跨屏接力，也能手动切换目标。
- 底栏沿用 LightOS 远程桌面的两行通用快捷键与系统键盘开关，移除画面、声音和远程桌面设置等专属操作。
- 首页和控制页隐藏懒猫宿主导航、保留系统状态栏，消费宿主或浏览器安全区；系统键盘展开时底栏保持可见。
- 返回首页、切后台、断线、接收端本地接管、暂停或撤销信任时结束控制并释放按键，不自动重放或恢复旧控制。

## 范围

LPK 内的网页与中枢。手机作为临时账号管理控制端，不创建持久设备、不绕过设备批准，不抢占其他控制端。浏览器输入通过中枢转发，仅直连或仅蓝牙模式下明确提示不可用。保留现有电脑客户端协议兼容性。

## 非目标

远程画面、更新电脑客户端、手机原生应用、改变现有桌面输入权限。网页无法复现实体按压、Force Touch 或触觉反馈，也不将捏合、旋转、系统桌面切换等操作伪装成通用键鼠指令。手机输入法提交的非按键文本可明确发送至当前设备剪贴板后手动粘贴，不承诺旧客户端具备直接 Unicode 注入能力。
