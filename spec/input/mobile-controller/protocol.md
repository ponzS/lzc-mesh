# 浏览器临时控制协议

本协议使用现有同源 `/api/ws` 和懒猫账号鉴权，不新增匿名或跨域入口。

- 管理页面发送 `{"t":"hello","platform":"web"}` 后，中枢通过 `welcome.id` 返回本连接的临时来源 `web:<连接序号>`。该命名含原生设备 ID 禁止使用的冒号，不写入布局，不发布直连证书。
- `{"t":"web_control","target":"<设备ID>"}` 仅账号管理连接可调用。目标必须属于本账号、已批准、在线、运行且开启键鼠共享；账号输入总开关须开启，模式须允许中转。拒绝时返回 `error.message`，不修改设置或抢占其他来源。相同浏览器手动更换目标会先结束旧控制并释放按键。
- 成功后沿用 `state.active`、原生 `enter/move/button/wheel/key/leave`，无需增加接收端消息类型。初始位置为目标中心，后续 `motion` 使用相对位移；跨屏由现有布局计算。鼠标按钮 `1=左，2=右，3=中`，按键为 evdev 码；按既有设置交换 Mac 的 Ctrl/Command。
- 浏览器每秒发送 `{"t":"web_alive","control_id":"<当前控制ID>"}`。只允许该来源续约自己的当前控制；四秒未续约后到期，中枢每秒检查并结束会话。过期后迟到的续约或输入不能复活旧会话。
- `release` 只结束本连接自己的控制。网页返回、失焦、隐藏和离开时发送；连接关闭、租约到期、接收端本地接管、暂停共享或撤销信任同样结束。重连需要用户重新点击开始，不重放输入。
- `{"t":"web_text","text":"<提交文本>"}` 仅当前浏览器控制来源可以使用，且必须开启共享剪贴板，大小不超过 256 KiB。只向当前目标发送已有 `clipboard` 消息，不广播到其他设备、不落盘。网页明确提示手动粘贴；不把剪贴板发送当作接收端已经完成异步更新，也不自动生成可能抢先到达的粘贴按键。

手机触控板使用原子多指快照识别手势，不用单独的 pointermove 事件推断双指中心，避免加指和抬指导致跳动。单指轻点左键、双指轻点右键、双指自然滚动、三指拖拽和轻点两下后滑动；不使用长按右键或额外拖拽开关。双指滚动以 `source=continuous` 传输，抬手后由网页按释放速度生成唯一一段带 `momentum_phase` 的衰减滚动，防止接收端另造惯性；新触摸、取消或控制结束立即停止。外接鼠标/触控板的浏览器 wheel 流已包含系统惯性，不再叠加。

首页和控制页沿用 LightOS 的 `lzcapp-navigation-bar-scheme=hidden`、`lzcapp-disable-dark=true` 与四边 `--lzc-safe-area-*`；宿主的显式零值优先于浏览器 `env(safe-area-inset-*)`。可见布局跟随 `visualViewport`，不强制系统全屏、不禁用页面缩放。底栏的两行按键与系统键盘输入方式移植自 LightOS Remote Desktop 的 `web/src/mobile.ts` 和 `App.tsx`，没有引入远程桌面运行时或专属操作。
