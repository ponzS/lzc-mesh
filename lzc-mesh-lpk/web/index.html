设备

    首次接入（包括升级后的已有设备）需先核对本机显示的完整设备指纹并批准。撤销信任与运行开关独立；未获信任的设备不能参与共享。请保护管理网页登录会话，它拥有批准设备和管理文件的权限。

    关闭某台客户端会停止它的键鼠、剪贴板、文件收发及直连，状态跨重启保留。后台仍在运行且网络可达时，可通过开关重新开启；不能唤醒已关机或真正退出的进程。

    设置

    局域网可达时自动直连，不可达时通过中枢转发。

    暂停会结束当前控制、释放按键，并关闭全部新版客户端的直连入口。

    跨屏切换时自动将鼠标光标移到屏幕中央。

    默认开启：在任一设备上复制的文本会同步到其他在线设备。剪贴板内容只在设备间转发，不保存在微服上。

    控制其他设备时，按 Ctrl + Alt + Esc 可立即把光标收回本机。

    客户端下载

    • macOS（Apple Silicon / Intel）安装包 .dmg压缩包 .zip
    • Windows 10/11 x64安装包 .exe压缩包 .zip
    • Linux x86_64（暂时仅 Omarchy）安装包 Arch压缩包 .tar.gz

    安装包托管在 GitHub Releases。客户端通过本机的懒猫微服客户端接入网络，使用前请先登录懒猫微服客户端。Linux 暂时仅支持 Omarchy，不支持其他发行版或桌面环境。
